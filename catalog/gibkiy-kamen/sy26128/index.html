SY26128

Гибкий камень с выразительной фактурой для декоративных интерьерных решений.

Для SY26128 оцените масштаб каменного рисунка рядом с соседним покрытием. Если на стене будет светильник, отметьте его положение и проверьте образец при похожем направлении света. На схеме для расчёта разделите участки, которые отделываются целиком и частично. Калькулятор поможет оценить количество листов по площади. Отдельно обозначьте места, где материал потребуется подрезать.
