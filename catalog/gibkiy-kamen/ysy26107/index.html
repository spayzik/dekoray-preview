Гибкий камень с выразительной фактурой для декоративных интерьерных решений.

Для YSY26107 посмотрите образец гибкого камня фронтально и при боковом свете. Сравните, какой рисунок останется виден после расстановки мебели. Для плоскости с проёмами отметьте ширину и высоту каждого участка, а оформление краёв согласуйте отдельно. Калькулятор поможет оценить количество листов по площади. Отдельно обозначьте места, где материал потребуется подрезать.
