Венецианская, шампань

Артикул 3203-254

Декоративная панель с фактурой штукатурки для интерьерного оформления.

«Венецианскую, шампань» можно поставить рядом с песочной фактурой той же серии для сравнения при дневном и тёплом свете. Для стены с зеркалом или крупной мебелью оценивайте образец на тех участках, которые останутся открыты на уровне глаз. Для предварительного подсчёта листов можно использовать калькулятор, а итоговую раскладку и подрезку согласовать по эскизу.
