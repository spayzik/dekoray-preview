Лён светло-серый

Артикул 8305-W

Декоративная панель с тканевой фактурой для интерьерного оформления.

Светло-серый лён стоит сравнить с кремовым льном на фоне пола, который уже есть в интерьере. Если в проекте несколько источников света, оцените образец при каждом. Для стены с открытыми боковыми краями подготовьте ширину зоны и схему примыканий. Для предварительного подсчёта листов можно использовать калькулятор, а итоговую раскладку и подрезку согласовать по эскизу.
