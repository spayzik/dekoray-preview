8141-P

Декоративная панель с тканевой фактурой для интерьерного оформления.

Для стены с нишей отдельно приложите образец 8141-P к основной плоскости и к откосу, если хотите продолжить оформление. Посмотрите, как граница ниши меняет восприятие фактуры. Подготовьте размеры обеих зон, чтобы менеджер мог уточнить раскладку. Для предварительного подсчёта листов можно использовать калькулятор, а итоговую раскладку и подрезку согласовать по эскизу.
